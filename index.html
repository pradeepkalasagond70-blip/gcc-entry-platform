Integration roadmap · post-MVP

The prototype is intentionally not connected to paid data feeds or a production backend.

Planned
Phase 1

Curated, source-backed imports

Start with public company announcements, official filings and published reports. Every record gets a source, date, definition and review status.

Phase 2

Evaluate API / licensed feeds

Test coverage, access terms, update frequency and field quality before paying for commercial data. Company registration data alone does not prove GCC status.

Phase 3

Backend ingestion + review queue

Normalize claims, retain provenance, flag conflicts and route material changes for human validation before updating recommendations.

No live integration is claimed. This prototype demonstrates the user workflow and evidence model; production ingestion would require source-by-source diligence, permitted access and testing.
